# سرور RDKit MCP — دسترسی عاملی به RDKit برای مدل‌های زبانی

> 📖 نسخه انگلیسی این راهنما: [README.md](./README.md)

**RDKit MCP Server** یک سرور متن‌باز بر پایه پروتکل **MCP** (Model Context Protocol) است که به مدل‌های
زبانی اجازه می‌دهد مستقیم با کتابخانه **RDKit** کار کنند — بدون اینکه لازم باشد شما حتی یک خط کد
بنویسید. کافی است از مدل بپرسید و او با زبان طبیعی، ابزارهای شیمی‌انفورماتیک RDKit را صدا می‌زند.

ساخته‌شده توسط **TandemAI** تحت مجوز **MIT** — نسخه اصلی این مخزن را ببینید:
https://github.com/tandemai-inc/rdkit-mcp-server

---

## این سرور به چه دردی می‌خوره؟

به زبان ساده: مد‌ل‌های زبانی در حرف زدن درباره داروها خوب‌اند، اما در **محاسبه** ضعیف‌اند؛ عددها را
حدس می‌زنند و گاهی «توهم محاسباتی» دارند. این سرور یک ماشین‌حساب شیمیایی دقیق را به مدل وصل می‌کند تا
به‌جای حدس زدن، واقعاً محاسبه کند.

### برای یک داروساز ایرانی یعنی چه؟

- **اعتبارسنجی SMILES:** ساختار یک دارو را بدهید (مثلاً آسپرین) و بفهمید SMILES آن سالم است یا نه،
  و شکل استاندارد (canonical) آن چیست.
- **محاسبه دیسکریپتورها:** وزن مولکولی، **logP** (چربی‌دوستی)، **TPSA** (مساحت سطح قطبی)، تعداد
  دهنده/گیرنده پیوند هیدروژنی، تعداد پیوندهای چرخان و فرمول مولکولی — همه با یک سؤال ساده.
- **قانون پنج لیپینسکی (Lipinski's Rule of Five):** بررسی سریع اینکه یک مولکول شبیه داروهای خوراکی
  است یا نه (MW ≤ ۵۰۰، logP ≤ ۵، HBD ≤ ۵، HBA ≤ ۱۰).
- **مقایسه مولکول‌ها:** شباهت دو دارو را با اثر انگشت مولکولی (Morgan fingerprint) و شاخص
  **Tanimoto** بسنجید؛ برای پیدا کردن جایگزین‌ها یا بررسی مشابهت ساختاری مفید است.
- **اسکلت مورکو (Murcko scaffold):** اسکلت اصلی یک مولکول را استخراج کنید؛ برای دسته‌بندی داروها
  و طراحی مشتقات جدید.
- **تبدیل فرمت‌ها:** تبدیل بین SMILES ،SDF ،PDB و تصویر دوبعدی مولکول.
- **ساختار سه‌بعدی:** تولید مختصات سه‌بعدی مولکول (EmbedMolecule) برای بررسی‌های بعدی مثل داکینگ.

### یک مثال واقعی

شما می‌پرسید:

> «آسپرین قانون پنج لیپینسکی را پاس می‌کند؟ logP و TPSA آن چقدر است؟»

مدل به‌جای حدس زدن، ابزارهای این سرور را صدا می‌زند و با عددهای واقعی RDKit جواب می‌دهد:
آسپرین (SMILES: `CC(=O)OC1=CC=CC=C1C(=O)O`) وزن مولکولی حدود ۱۸۰٫۱۶، logP حدود ۱٫۳ و TPSA حدود
۶۳٫۶ Å² دارد و هر چهار قانون لیپینسکی را پاس می‌کند.

## نصب

```bash
pip install .
```

نیازمند Python نسخه ۳٫۱۰ یا بالاتر است. وابستگی‌ها در `pyproject.toml` آمده‌اند
(RDKit نسخه 2025.3.1، MCP SDK، Pillow، Pydantic).

## اجرا

```bash
python run_server.py [--settings settings.yaml]
```

به‌صورت پیش‌فرض با transport ‏`sse` روی پورت ۸۰۰۰ بالا می‌آید؛ برای اتصال مستقیم به
کلاینت‌های MCP (مثل Claude Desktop) از stdio استفاده کنید:

```bash
python run_server.py --transport stdio
```

نمونه تنظیمات در `settings.example.yaml` است (لیست مجاز/ممنوع ابزارها).

## فهرست ابزارها

```bash
python list_tools.py [--settings settings.yaml]
```

ابزارها در چند گروه‌اند (همه از دل RDKit نسخه 2025.3.1 بیرون آمده‌اند):

| گروه | نمونه ابزارها |
|---|---|
| دیسکریپتورها | `MolWt` ،`ExactMolWt` ،`CalcTPSA` ،`CalcCrippenDescriptors` (logP) ،`CalcNumHBA` ،`CalcNumHBD` ،`CalcNumRotatableBonds` ،`CalcMolFormula` |
| تبدیل فرمت | `smiles_to_mol` ،`mol_to_smiles` ،`mol_to_sdf` ،`sdf_to_mol` ،`mol_to_pdb` ،`pdb_to_mol` |
| شباهت و زیرساختار | `TanimotoSimilarity` ،`GetSubstructMatch` ،`HasSubstructMatch` ،`MurckoScaffoldSmilesFromSmiles` |
| تصویر و سه‌بعدی | `MolToImage` ،`MolsMatrixToGridImage` ،`EmbedMolecule` ،`EmbedMultipleConfs` ،`Compute2DCoords` |
| پردازش دسته‌ای | `batch_map` (اجرای یک ابزار روی لیستی از ورودی‌ها) |

## کلاینت خط فرمان (CLI)

برای آزمایش سریع با OpenAI:

```bash
export OPENAI_API_KEY="sk-proj-xxx"
python run_client.py
```

## ارزیابی‌ها

پوشه `evals` مجموعه تست ارزیابی خروجی ابزارها و پاسخ عامل با
[pydantic-evals](https://ai.pydantic.dev/evals/) است:

```bash
pip install ".[evals]"
python run_server.py          # در یک ترمینال
python evals/run_evals.py     # در ترمینال دیگر
```

## نسخه داروسازی برای ایران: `pharmacy-mcp/`

روی همین موتور، یک سرور کوچک‌تر و تخصصی‌تر برای نیازهای داروسازی در ایران ساخته شده است
(پوشه [`pharmacy-mcp/`](./pharmacy-mcp/)): بررسی لیپینسکی، دیسکریپتورهای دارویی، اعتبارسنجی
SMILES، شباهت اثر انگشت و جست‌وجوی نمونه‌ای داروها — با هشدار صریح اینکه داده‌های بازار ایران
(برند، دوز، قیمت، موجودی) را **باید از منابع خودتان** (سایت پیام‌داروساز / سالنامه سازمان غذا و
دارو) بررسی کنید، نه از نمونه‌های داخل کد. راهنمای نصب و اجرا در
[`pharmacy-mcp/README.md`](./pharmacy-mcp/README.md) است.

## محدودیت‌ها — صادقانه بخوانید

- این سرور **محاسبه‌گر ساختار** است، نه مرجع بالینی: دوز، تداخل، اندیکاسیون و عارضه را نمی‌داند
  و نباید از آن برای تصمیم درمانی استفاده کرد.
- خروجی‌ها بر اساس ساختار SMILES ورودی‌اند؛ اگر SMILES اشتباه باشد، همه عددها اشتباه می‌شوند.
- logP محاسبه‌شده (Crippen) یک **تخمین** است، نه مقدار تجربی.
- RDKit نسخه ۲۰۱۸ یا منابع قدیمی دیگر در این مخزن استفاده نشده‌اند؛ مبنای محاسبات RDKit 2025.3.1 است.
